## 4. How to Run Live Demonstrations

### 1. Requirements Installation
```bash
pip install -r requirements.txt
```

### 2. Run Complete Pytest Suite (107 Tests)
```bash
pytest
```

### 3. Run Live CLI Benchmark Demo (No Setup Required)
```bash
python samdhan_cli.py demo
```

### 4. Assess Any Specific File via CLI
```bash
python samdhan_cli.py assess sample_data/invoice.jpg
python samdhan_cli.py assess sample_data/incident_audit.db
```

### 5. Start Unified FastAPI Backend + Interactive Dashboard
```bash
python -m uvicorn backend.api:app --host 127.0.0.1 --port 8000
```
- Open `http://localhost:8000/dashboard` or `http://localhost:8000/` for the interactive dashboard.
- Open `http://localhost:8000/docs` for the interactive OpenAPI/Swagger UI.
- React/Vite development server runs via `npm run dev` at `http://localhost:5173`.
